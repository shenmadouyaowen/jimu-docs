# 1 分钟上手积木智能体（Jimu Harness）：填个 Key、选个模型就能用

如果你用过 Coze、Dify 这类网页版智能体平台，积木智能体（Jimu Harness）可能会让你眼前一亮——它是个**桌面原生客户端**（macOS / Windows），智能体可以直接读写你电脑上的文件、执行终端命令、连接本地 MCP 服务，这些是浏览器沙箱里做不到的。

上手真的只要 1 分钟：

## 第 1 步：下载客户端

去官网 jimu.chat 下载对应系统的客户端，安装打开。主界面很干净：左侧是新对话、全局搜索、市场资源、定时任务等入口，中间一句话输入框，底部可以直接切换模型。

[图2：客户端主界面]

## 第 2 步：填 API Key

打开设置里的渠道管理，新增三方渠道：填个渠道名称，选择供应商类型，填入 Base URL 和 API Key，点"获取模型"就能拉取模型列表。

[图1：新增三方渠道]

一个 Key 就聚合了 GPT、Claude、Gemini、DeepSeek 等主流模型，不用每个平台各办各的 Key。

## 第 3 步：选模型，开用

回到对话框，在底部的模型选择器里选一个（比如 deepseek-v4.1-flash），直接开聊；也可以创建一个智能体，配上提示词和工作流，全程不用写代码。

就这么简单。之后可以试试它的看家本领：让智能体整理你电脑里的文档、跑一段本地脚本——这是网页版智能体碰不到的天花板。

官网：jimu.chat

**一句话 FAQ**：和 Coze 有什么区别？Coze 是网页版，适合快速把机器人发到抖音、飞书；Jimu Harness 是桌面版，适合需要动本地文件、跑命令的企业场景。
