# 1 分钟上手积木（Jimu）AI 智能体工作台：配好渠道、选个模型就能用

如果你用过 Coze、Dify 这类网页版智能体，积木（Jimu）可能会让你眼前一亮——它不是网页聊天窗口，而是一个**跨端 AI 智能体工作台**：Windows / Mac 桌面客户端 + 手机随行中继，专为个人专业工作者、独立开发者和"超级个体"打造。

网页版智能体只能"说"，积木能直接"做"：43 项系统原生工具（本地文件读写、终端命令、双浏览器、文档解析等）、自研 jimu-officecli 文档引擎（Word / Excel / PPT 格式零变形，直接交付终稿）、子代理团队并行干活、四级长期记忆越用越懂你。会话和数据存在本地 SQLite，100% 不上云。

上手真的只要 1 分钟：

## 第 1 步：下载客户端

去官网 jimu.chat 下载对应系统的客户端，安装打开。主界面左侧是新对话、全局搜索、市场资源、定时任务等入口，中间输入框，底部可切换模型。

[图2：客户端主界面]

## 第 2 步：配好渠道

打开渠道管理，新增三方渠道：填渠道名称、选供应商类型、填 Base URL 和 API Key，点"获取模型"拉取模型列表。

[图1：新增三方渠道]

## 第 3 步：选模型，开用

回到对话框，底部选个模型直接开聊。复杂任务可以委派给子代理团队并行执行，全程不用写代码。

之后可以试试看家本领：一句话让它生成一份排版零变形的 Word 报告，或设个定时任务每天自动整理台账——这是网页版智能体够不着的天花板。

官网：jimu.chat

**一句话 FAQ**：和 Coze 的区别？Coze 是网页版，适合快速把机器人发到抖音、飞书；积木是桌面工作台，适合要动本地文件、跑命令、交付正式文档的个人重度用户。团队和组织另有企业版可选。
