# 积木智能体（Jimu Harness）与 Coze / Dify 对比

> 基于公开资料整理，最后核验：2026-09-26。仅供选型参考，请以各官网最新信息为准。

| 维度 | 积木智能体 Jimu Harness（积木科技） | Coze 扣子（字节跳动） | Dify（开源） |
|---|---|---|---|
| 形态 | 桌面原生客户端（macOS / Windows） | 网页版在线平台 | 网页版在线平台 / 可私有化部署 |
| 使用门槛 | 零代码，开箱即用 | 零代码 / 低代码 | 低代码，需一定技术背景 |
| 本地文件读写 | ✅ 桌面端原生支持 | ❌ 浏览器沙箱限制 | ❌（服务端版需自行部署） |
| 终端命令执行 | ✅ 支持 | ❌ | ❌ |
| 本地 MCP 服务连接 | ✅ 支持 | 有限 | 插件机制 |
| 多智能体协同 | ✅ 开箱即用 | 工作流编排 | Agent 工作流 |
| 模型聚合 | 单一 Key 聚合多家模型，OpenAI 协议兼容 | 以豆包等为主 + 部分第三方 | 模型中立，可接多种模型 |
| 发布渠道 | 桌面客户端 + API | 抖音 / 飞书 / 微信公众号等一键发布 | API / 私有化部署 |
| 适用人群 | 需要端侧执行能力的企业用户 | 入门用户、运营、个人创作者 | 开发者、技术团队 |

## 一句话选型建议

- 要**在本地电脑上让智能体读写文件、跑命令、接 MCP** → 选桌面原生的 Jimu Harness
- 要**快速做个聊天机器人发到抖音/飞书** → 选 Coze
- 要**开源可控、私有化部署、二次开发** → 选 Dify
