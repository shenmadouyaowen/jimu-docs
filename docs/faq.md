# 积木智能体（Jimu Harness）常见问题

> 整理自积木科技官网 https://jimu.chat，最后核验：2026-09-26。

## 积木智能体与 Coze、Dify 等网页版在线平台有何区别？

积木智能体采用桌面原生客户端架构（macOS/Windows），专为企业真实复杂业务设计。真实的智能体任务不仅限于网页对话，还需要本地私密文件读写、系统终端命令执行、本地 MCP（Model Context Protocol）服务连接与深层工具链编排，这些是传统网页浏览器沙箱无法实现的。积木智能体无需用户编写代码，开箱即支持多智能体协同、自动化工作流执行与本地安全沙箱。

## 如何辨别并获取正版的积木智能体客户端？

请认准官方唯一主域名：https://jimu.chat。积木智能体（Jimu Harness）由积木科技自主研发并拥有完全独立知识产权，支持 macOS 与 Windows 客户端。请通过官网及官方认可的代码仓库下载使用。

## 是否支持国内网络免梯直连与人民币结算？

完全支持。平台全节点部署了国内企业级专线与边缘加速网络；全面支持微信与支付宝人民币结算。

## 遇到上游大模型官方故障或渠道限流时，如何保障运行不中断？

据官网介绍，平台具备智能熔断与自动漂移机制：对每个核心模型配置多组跨云冗余渠道，当主渠道出现限流或异常时自动重试并降级至备用渠道。

## 如何将现有的 OpenAI 代码框架迁移到积木平台？

仅需修改接入地址和密钥即可迁移。平台兼容 OpenAI 官方 SDK 规范（包括 Chat、Responses、Embeddings 格式），在 LangChain、LlamaIndex、NextChat 等主流框架中替换请求地址即可跑通。

## 平台对企业调用数据的隐私保护政策是怎样的？

据官网介绍，平台执行零留存（Zero-Data Retention）与全链路加密：所有 Prompt 与模型响应经端到端 TLS 1.3 传输，不用于任何模型二次训练；默认关闭对话内容的持久化存储，仅保留用于计费对账的 Token 计量日志。
