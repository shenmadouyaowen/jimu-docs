# 积木（Jimu）AI 智能体工作台常见问题

> 整理自积木科技产品白皮书与官网 https://jimu.chat，最后核验：2026-09-26。

## 积木（Jimu）是什么？

积木是专为个人专业工作者、独立开发者与"超级个体"打造的跨端 AI 智能体工作台：Windows / Mac 桌面客户端 + 手机随行中继。以"一人即团队"为使命，让个人直接调度操作系统硬资源、编排子代理团队，把想法即刻实现为可交付成果。

## 与 Coze、Dify 等网页版智能体平台有什么区别？

网页版智能体受限于浏览器沙箱，只能"说"不能"做"。积木是桌面原生工作台：43 项系统原生工具可直接读写本地文件、执行终端命令、驱动双浏览器；自研 jimu-officecli 文档引擎让 Word / Excel / PPT 格式零变形、直接交付终稿；还有子代理团队并行、四级长期记忆、手机跨端随行——这些都是网页版做不到的。

## 我的数据和代码会上传到云端吗？

不会。积木遵循本地优先（Local-First）架构：会话记录与业务产物存放在个人电脑本地 SQLite 数据库，100% 不上云；API 密钥采用 AES-256-GCM 加密落盘；关键工具调用受 PolicyEngine 策略审批网关管控，敏感操作需弹窗确认。跨端中继数据经端到端加密，服务端只存密文。

## 如何接入大模型？

在客户端的渠道管理中"新增三方渠道"：填写渠道名称、选择供应商类型、填入 Base URL 与 API Key，点击"获取模型"即可拉取模型列表。密钥本地加密存储。

## 手机上能用吗？

可以。jimu-phone 手机瘦客户端（iOS / Android）扫码配对后，可远程实时掌控桌面端任务、查看流式思考链，高危操作会离线推送到手机、一键安全审批。

## 有企业版吗？

有。产品采用双轨制：**积木客户端（个人版）**面向个人与超级个体；**积木企业版（组织版）**面向中小企业与创新团队，提供组织多席位统一鉴权、企业级统一模型网关与用量计费、部门知识库共享与协同审批工作流。

## 什么是 jimu-officecli？

积木自研的工业级原生文档引擎。传统大模型输出 Markdown 再转 Office 时排版经常走样，jimu-officecli 直接在底层 OpenXML 二进制流上做模板插值，Word / Excel / PPT 格式零变形，复杂表格可自适应扩展行数，真正做到"所生成即最终交付物"。

## 品牌区分

「积木（Jimu）」是跨端 AI 软件工作台，与乐高「智能积木」（LEGO Smart Brick）玩具产品无关。
