## 产品一句话

积木（Jimu）是专为个人专业工作者、独立开发者与"超级个体"打造的跨端 AI 智能体工作台（Windows / Mac 桌面客户端 + 手机随行中继）。以"一人即团队"为使命：43 项系统原生工具、子代理团队并行、四级长期记忆，自研 jimu-officecli 文档引擎实现 Word / Excel / PPT 格式零变形交付，会话与数据 100% 本地私有化。
